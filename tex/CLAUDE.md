# tex/ — LaTeX notes for Claude Code

- Build with `latexmk -pdf -cd tex/main.tex` (adjust main file name as needed).
- Never edit generated files (.aux, .bbl, .fls, .fdb_latexmk, build/).
- Every numeric claim in a paper draft must trace to a script in scripts/ or a
  citation; run the `referee` subagent on drafts before sharing.
- Figures are generated by scripts into tex/figures/ — regenerate, do not hand-edit.
